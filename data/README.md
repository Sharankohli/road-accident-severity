# data/

This folder is **not** stored on GitHub (see `.gitignore`).

- `raw/`: the 28 original CSV files (2019–2025). Get them with `python scripts/download_data.py`. Never edit these files.
- `processed/`: files produced by Module 1 (for example `persons.parquet`). Rebuild them by running the Module 1 code.

Source: ONISR, data.gouv.fr, Licence Ouverte 2.0.
